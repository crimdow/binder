      Places from Google Maps

      1. In Google Maps (or Apple Maps), open the place and tap Share → Copy link.
      2. In the binder, go to Places, tap + and paste the link. The name, address and map spot fill in; add your tags and Save.
      3. On a laptop or in Safari, Add to Binder works on a Google Maps place page or a restaurant’s, park’s or museum’s own page too.

      One tap from the Maps or Google app (optional second shortcut)

      1. In Shortcuts, tap +, name it Add Place to Binder, tap ⓘ and turn on Show in Share Sheet. In the top block, keep only URLs and Text.
      2. Add Text and put Shortcut Input in it. (Google Maps shares the name, address and link together; this keeps all three.) Don’t add Run JavaScript here.
      3. Add URL Encode (it picks up that Text).
      4. Add Text and type https://binder.jermins.com/#add&u=, then tap URL Encoded Text above the keyboard to put it at the end.
      5. Add Open URLs.
      6. In Google Maps or a Google listing: Share → Add Place to Binder. Binder opens in Places with it looked up.

      Share shortcut (iPhone)

      1. Tap Copy shortcut script below.
      2. In Shortcuts, tap +, name it Add to Binder, tap ⓘ and turn on Show in Share Sheet. In the top block, keep only Safari web pages.
      3. Add Run JavaScript on Web Page. Tap into its code box, select all, and paste.
      4. Add Open URLs. It picks up the JavaScript Result on its own.
      5. Turn on scripts once: Settings → Apps → Shortcuts → Advanced → Allow Running Scripts.
      6. In Safari: Share → Add to Binder. The binder opens with the text, title and link filled in. Check it and tap Save.

      Bookmark (laptop)

      1. Show your bookmarks bar (Chrome or Edge: Ctrl/⌘+Shift+B · Safari: View → Show Favorites Bar).
      2. Drag this button up onto the bar: Add to Binder
      3. On any page with lyrics, a story, a tab or a recipe, click Add to Binder. The binder opens in a new tab with it filled in. Check it and tap Save.

      Can’t drag? Copy the code, make a new bookmark, and paste it in as the address.
