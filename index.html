      Share shortcut (iPhone)

      1. Tap Copy shortcut script below.
      2. In Shortcuts, tap +, name it Add to Binder, tap ⓘ and turn on Show in Share Sheet. In the top block, keep only Safari web pages.
      3. Add Run JavaScript on Web Page. Tap into its code box, select all, and paste.
      4. Add Open URLs. It picks up the JavaScript Result on its own.
      5. Turn on scripts once: Settings → Apps → Shortcuts → Advanced → Allow Running Scripts.
      6. In Safari: Share → Add to Binder. The binder opens with the text, title and link filled in. Check it and tap Save.
